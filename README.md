# Lightweight Strategical Markers

A client-side [Darktide Mod Framework (DMF)](https://github.com/Darktide-Mod-Framework/Darktide-Mod-Framework) mod for Warhammer 40,000: Darktide. It shows markers on ammo, grenade refills, medical crates, stimms, health stations and chests, using the game's own icons.

It is built to cost as little as possible: no game function is replaced, items are found when they spawn instead of by scanning, and only items within the marker distance get a marker.

## Install

1. Install and enable Darktide Mod Framework and its required mod loader.
2. Place the `LightweightStrategicalMarkers` folder in Darktide's `mods` folder, so the path is `mods/LightweightStrategicalMarkers/LightweightStrategicalMarkers.mod`.
3. Add `LightweightStrategicalMarkers` as a line in `mods/mod_load_order.txt` and start the game.
